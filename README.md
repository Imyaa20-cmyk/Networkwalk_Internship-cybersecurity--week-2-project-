1. Project Overview

This repository documents my Week 2 practical projects as part of the Networkwalks Cybersecurity Internship.

The project focuses on cybersecurity footprinting, reconnaissance techniques, network scanning and penetration testing documentation.

The practical activities involve using selected cybersecurity tools to gather information within authorised testing environments, understand network exposure and identify information that may be relevant to security assessments.

The project consists of an elective footprinting module, a compulsory Zenmap-based network scanning module and a final penetration testing report.

2. Project Objectives

The objectives of this project are to:

- Understand the fundamentals of cybersecurity footprinting.
- Practise information gathering using selected reconnaissance tools.
- Understand how footprinting supports penetration testing.
- Perform network scanning using Zenmap.
- Identify hosts and exposed network services within an authorised lab.
- Understand the importance of documenting security observations.
- Develop professional penetration testing reporting skills.
- Apply ethical and legal principles throughout security assessments.
